# USA Business Scraper

A desktop Python application that helps users find publicly available small-business contact information by business type and U.S. state.

## Features

- Search one or more business types across selected states
- Find business names, websites, email addresses, and phone numbers
- Filter out common directories and social-media sites
- Preview results in the application
- Export results to CSV or Excel

## Built With

- Python
- Tkinter
- Selenium
- OpenPyXL

## How to Run

```bash
pip install selenium openpyxl
python main.py
```

## Note

This project is for educational use and collecting publicly available business information. Use it responsibly and respect website terms of service.
